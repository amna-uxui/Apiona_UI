# Living Record

UI and visual design work for the pre-consultation experience: helping a practitioner understand a patient's medical history before the first visit. The patient's record is drawn as a living, growing structure (a garden of cells) instead of a stack of documents.

Focus scenario: a patient with SEDH (hypermobile Ehlers-Danlos syndrome) before their first visit with a psychotherapist.

## Folders

- `concepts/` — interactive concept prototypes
  - `living-record.html` — the record as a cross-section that grows a ring each year; zoom from body system to moment to source document

- `design/` — the design system
  - `tokens.css` — colours (cream, black, white, blue first; yellow, pink and green as markers) and type (Helvetica Neue)
  - `specimen.html` — a page showing the logo, palette, type and record colours together
  - `logo/` — Apiona logo: `apiona-logo.svg` (black, or any colour via CSS) and `apiona-logo-white.svg`

Planned as we go:

- `references/` — mood board and visual references
- `frames/` — UX frames from the team

Open the HTML file in a browser (double-click it in Finder). All patient data in the prototypes is invented.
